# Инструкции за Claude

## Нов проект = ново repository

Когато потребителят започне нов проект (напр. „искам да направим…“, „нов проект за…“, „започваме…“), **винаги създавай отделно GitHub repository за него**, преди да пишеш код или файлове. Не слагай проекти в `katarzyna` — то е само „начална точка“ и съдържа тези инструкции.

Стъпки:

1. Измисли кратко име в kebab-case на английски според проекта (напр. `longevity-coach-content`, `todo-app`). Ако не е ясно какъв е проектът, попитай с едно кратко изречение.
2. Създай repository с `mcp__github__create_repository`:
   - акаунт: `grzlvc11` (лично, без organization)
   - `private: true`, освен ако потребителят не каже „публично“
   - `autoInit: true` (с README)
   - `description`: едно изречение за проекта
3. Добави го в сесията с `mcp__claude-code-remote__add_repo` (`access: "push"`), клонирай го и регистрирай с `register_repo_root`.
4. Копирай този `CLAUDE.md` в новото repository, за да важат същите правила и там.
5. Работи по проекта в новото repository и кажи на потребителя линка към него.

Не трий repositories без изрично разрешение от потребителя.

Потребителят пише на български — отговаряй на български.
